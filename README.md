# DES432 Project 2: Statistical Modeling & Interpretation

## Overview
This project analyzes the relationship between **monthly income, expenses, and savings** using statistical methods.

## Objectives
- Perform exploratory data analysis (EDA)
- Conduct statistical inference (Spearman correlation)
- Build a multiple linear regression model
- Evaluate and interpret the model

## Dataset
- Source: Kaggle (Personal Finance ML Dataset)
- Key variables:
  - monthly_income_usd
  - monthly_expenses_usd
  - savings_usd

## Methods
- Data visualization (scatter plots)
- Spearman correlation test
- Multiple Linear Regression (OLS)
- Model evaluation (R², residual analysis)

## Results
- Moderate positive relationship between income and savings
- Income is statistically significant
- Expenses are not statistically significant
- Model shows moderate fit (R² ≈ 0.365)
- Residual plot indicates heteroscedasticity

## How to Run
1. Open `Project2.ipynb`
2. Install required libraries:
   - pandas
   - seaborn
   - matplotlib
   - scipy
   - statsmodels
3. Run all cells
